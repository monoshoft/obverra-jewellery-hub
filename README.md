# OBVERRA DIGITAL — 4-in-1 Luxury Jewellery Website Demo Hub

A premier, production-grade 4-in-1 Luxury Jewellery Website Demo Hub engineered for fine jewellery brands, couture houses, and modern boutiques.

Built by **OBVERRA DIGITAL** to showcase four completely distinct digital directions on a unified, high-performance platform.

---

## 🌟 The Four Distinct Design Concepts

1. **Design A — Noir Luxe (`/design-a` · AURIGA JEWELS)**
   - **Aesthetic:** Obsidian black, midnight charcoal, champagne gold, warm ivory type.
   - **Hero:** "Jewellery That Tells Your Story" with interactive 3D Solitaire Ring on dark rock.
   - **Key Features:** Metric counters (5000+ happy customers, 100% certified), iconic category cards, high-contrast serif headlines, 3D diamond refraction, lifetime maintenance assurance.

2. **Design B — Ivory Elegance (`/design-b` · VELORA FINE JEWELLERY)**
   - **Aesthetic:** Warm ivory, pearl white, champagne gold, soft linen beige.
   - **Hero:** "Modern Jewellery for Every Moment" featuring architectural editorial archways, high-fashion model portrait, trust badges (Certified, Free Shipping, Secure Payment, Lifetime Exchange).
   - **Key Features:** Arched portrait category cards (Rings, Necklaces, Earrings, Bracelets, Mangalsutra, Wedding Sets), quiet luxury editorial styling, dedicated 3D cushion halo viewer.

3. **Design C — Royal Heritage (`/design-c` · RAJATVAM JEWELS)**
   - **Aesthetic:** Imperial emerald green, antique 22K gold, warm ivory, royal maroon.
   - **Hero:** "Heritage Crafted for Today" with Indian bridal emerald & syndicate Polki choker on emerald velvet bust, 360° interactive 3D View badge, heritage metrics (25+ years, 10,000+ brides, BIS 916).
   - **Key Features:** Featured collection cards (Bridal, Gold, Diamond, Temple, Custom), Rajasthani & Mughal craftsmanship story, sacred Kundan & Meenakari detailing.

4. **Design D — Future Luxe (`/design-d` · LUMIERE JEWELLERY)**
   - **Aesthetic:** Cosmic midnight blue, platinum silver, starlight white, electric cyan.
   - **Hero:** "More Than Jewellery, It's a Feeling" with floating orbital platinum diamond solitaire, vertical slide pagination indicator (01, 02, 03).
   - **Key Features:** Hero feature cards (3D Custom Design, Premium Craftsmanship, Lifetime Support), generative algorithmic CAD studio, tension-set diamond suspension.

5. **Demo Hub (`/hub` or default `/`)**
   - **Branding:** OBVERRA DIGITAL agency flagship landing page.
   - **Hero:** "Four Visions. One Extraordinary Jewellery Experience."
   - **Features:** Four screenshot-style live rendered preview cards, comprehensive Strategic Comparison Matrix, architecture breakdown, and "Start Your Jewellery Project" inquiry workflow.

## 💎 Full-Featured E-Commerce System

- **Interactive 3D WebGL Atelier (Three.js & React Three Fiber):**
  - Physically-based diamond refraction (IOR 2.417, dispersion, transmission).
  - Real-time metal finish switcher: 18K Yellow Gold, 18K Rose Gold, 18K White Gold, Platinum 950.
  - Interactive orbit rotation and smooth auto-spin.
  - Hardware-accelerated with graceful fallback support.
- **Product Detail Modal (PDP):**
  - Switch seamlessly between High-Res Studio View and Interactive 3D Atelier.
  - Ring size selector (US 5 - 10 / Indian sizes with concierge size kit).
  - Complete specifications table (Gross weight, net gold weight, diamond carat, clarity, BIS 916 / IGI certification).
- **Shopping Bag (Cart Drawer):**
  - Dynamic subtotal, free insured delivery calculation, and promo code support (`OBVERRA10`).
  - Complimentary velvet gift packaging toggle.
- **Wishlist Drawer:**
  - Save pieces, view saved collection, move directly to shopping bag.
  - Instant live keyword filtering across categories, metals, gemstones, and designs.
- **Demo Checkout Modal:**
  - Armored courier inspection on delivery (COD) or Instant demo transfer.
  - Indian address verification fields (City, State, Pincode).
  - Confetti celebration upon demo order placement with generated Order ID (e.g. `#OBV-84920`).
- **Private Video & Boutique Appointment Booking:**
  - Reserved slots for salons in Mumbai, Delhi, Bangalore, London, and Dubai.
- **Custom Bespoke 3D CAD Atelier:**
  - Commission custom rings and bridal ensembles with certified gemologists.
- **Discreet Demo Floating Bar:**
  - Mobile-safe, collapsible switcher pill docked at the bottom right.
  - Allows instant toggling between Demo Hub and all four designs without obstructing top navigation.

## 🚀 Installation & Local Development

```bash
# 1. Install dependencies
npm install

# 2. Run the development server (runs on port 3000)
npm run dev

# 3. Create production build
npm run build

# 4. Preview production build
npm run preview
```

## 🛠️ Technology Stack

- **Framework:** React 19, TypeScript
- **Styling:** Tailwind CSS v4
- **3D Graphics:** Three.js, React Three Fiber, @react-three/drei, OrbitControls
- **Animation:** GSAP, Motion, Canvas-Confetti
- **Icons:** Lucide React
- **Bundler:** Vite 8
